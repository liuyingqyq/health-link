# 手机端安装指南

> 目标：把 `mobile/harmonyos/` 这个 HarmonyOS 应用装到你的手机上。
> 本机实测环境：**DevEco Studio 26.0.0.821**，内置 SDK **API 26（HarmonyOS 26.0.0）**。

---

## 0. 先看这个：两件事要分清

| | 装上能打开 | 能真正采到健康数据 |
| --- | --- | --- |
| 需要什么 | 签名 + 数据线 | 上面这些 **＋** 华为运动健康授权 |
| 耗时 | 约 10 分钟 | 额外 **约 15 个工作日**（华为人工审核） |

**关键提醒**：华为的健康数据权限是**人工审核**的。没有它，App 能装能开，
但点「请求健康数据授权」会返回未通过，采集不到真实数据
（错误码 201 / 1002702001 / 1002703001，见第 6 节）。

想先确认整条链路是通的，可以**先只做第 1~5 步装上**，然后用
`tools/phone-sim.js` 从电脑端灌模拟数据 —— 那部分不需要任何华为权限。

### 0.1 版本兼容：HarmonyOS 5 / 6 / 7 都能装

**已核实：HarmonyOS 7 = API 26**，而本机 SDK 正是 API 26
（`sdk-pkg.json` 里 `"apiVersion": "26"`、`"displayName": "HarmonyOS 26.0.0"`），
所以开发工具和你的手机是匹配的。

| HarmonyOS 系统 | API level | 本工程 |
| --- | --- | --- |
| HarmonyOS 5.0 | API 12 | ✅ 可装（这也是最低支持版本） |
| HarmonyOS 6.0 / 6.1 | API 20 / 23 | ✅ 可装 |
| **HarmonyOS 7** | **API 26** | ✅ **可装，代码无需修改** |

工程现在只声明**最低**兼容版本，**不写目标版本**（交给构建时的 SDK 决定）：

```json5
// mobile/harmonyos/build-profile.json5
"compatibleSdkVersion": "5.0.0(12)"     // 最低 API 12
// 刻意不写 targetSdkVersion

// mobile/harmonyos/AppScope/app.json5
"minAPIVersion": 12
// 刻意不写 targetAPIVersion
```

**为什么去掉目标版本**：写死成低于设备 API 的值（我原先写的是 `6.1.0(23)`，
装在 API 26 的手机上）**可能**触发安装报错
`compatibleSdkVersion and releaseType of the app do not match ...`。不写就没这个问题。

代码里用到的接口最低要求我已逐个核对：HealthServiceKit 全部 `@since 5.0.0(12)`
且 **0 个 `@deprecated`**，长时任务 / preferences 是 API 9，WebSocket 更低
—— 在 API 26 上都没问题。完整分析（含装不上时怎么改）见
[`docs/版本兼容说明.md`](版本兼容说明.md)。

## 1. 前置准备

### 1.1 电脑上要有 DevEco Studio

你机器上已经有了：`D:\Downloads\DevEco Studio`（版本 26.0.0.821）。

> 换电脑的话从 https://developer.huawei.com/consumer/cn/deveco-studio/ 下载安装。

### 1.2 手机上要做三步

| # | 操作 | 路径（HarmonyOS 6.x） |
| --- | --- | --- |
| 1 | 打开**开发者模式** | 设置 → 关于本机 → 连续点击「版本号」7 次，直到提示"已进入开发者模式" |
| 2 | 打开 **USB 调试** | 设置 → 系统和更新 → 开发者选项 → USB 调试 |
| 3 | 允许**安装未知来源应用** | 开发者选项里如果有「仅充电模式下允许 ADB 调试」，一并打开 |

> 部分机型「开发者选项」在 设置 → 系统和更新 → 开发人员选项。

### 1.3 用数据线连上电脑

连上后手机会弹「是否允许 USB 调试」，点**允许**（建议勾选"始终允许"）。

验证连接（用 DevEco 自带的 hdc）：

```powershell
& 'D:\Downloads\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe' list targets
```

看到一串设备号（如 `7001005458323933328XXXXXX`）就说明连上了。
显示 `[Empty]` 就回到 1.2 检查。

> 需要把 hdc 加到 PATH 的话：它就在上面那个 toolchains 目录里。

## 2. 配置签名（必须，否则装不上）

HarmonyOS 要求所有应用必须签名才能安装。**不需要你去买证书**，
DevEco 可以自动生成一个用于调试的签名。

1. 用 DevEco Studio 打开工程：
   `File → Open` → 选 **`<项目目录>\phone`** 目录
   （注意是 `phone` 目录，不是 `health-link`）

2. 等右下角 `Sync` 跑完（首次可能要几分钟，它会自动装 ohpm 依赖）。

3. 打开签名配置：
   `File → Project Structure...` → 左侧选 **Signing Configs**

4. 勾选 **`Automatically generate signature`**（自动生成签名）

5. 按提示**登录华为开发者账号**（没有就先去
   https://developer.huawei.com/consumer/cn/ 注册，免费）

6. 等它自动填好 4 个字段后点 **Apply → OK**：

   | 字段 | 说明 |
   | --- | --- |
   | Store file | 自动生成的 `.p12` 密钥库 |
   | Store password | 自动生成 |
   | Key alias | 自动生成 |
   | Profile file | 自动生成的 `.p7b` 调试证书 |
   | Certpath file | 自动生成的 `.cer` |

> ⚠️ 这一步必须有网。工程里的 `build-profile.json5` 的 `signingConfigs` 我故意留空，
> 就是等 DevEco 在这里生成，而不是预置一个用不了的证书。

## 3. 编译并安装（三种方式，选一种）

### 方式 A：一键运行（推荐，最省事）

1. DevEco 顶部工具栏的设备下拉框里选中你的手机
   （显示机型名而不是 `No Devices`）
2. 点绿色 ▶ **Run 'entry'** 按钮（或按 `Shift+F10`）
3. 等编译完成，App 会自动安装并启动

首次编译约 1~3 分钟。

### 方式 B：先编译出 HAP，再手动装

```powershell
# 1) 在 DevEco 里构建：Build → Build Hap(s)/APP(s) → Build Hap(s)
#    产物在：mobile\harmonyos\entry\build\default\outputs\default\entry-default-signed.hap

# 2) 用 hdc 安装
$hdc = 'D:\Downloads\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
& $hdc install -r "<项目目录>\mobile\harmonyos\entry\build\default\outputs\default\entry-default-signed.hap"
```

`install -r` 的 `-r` 表示覆盖安装（已装过就替换，保留数据）。

常用 hdc 命令：

| 命令 | 作用 |
| --- | --- |
| `hdc list targets` | 列出已连接设备 |
| `hdc install -r xxx.hap` | 覆盖安装 |
| `hdc uninstall com.healthlink.collector` | 卸载 |
| `hdc shell aa start -a EntryAbility -b com.healthlink.collector` | 从命令行拉起应用 |
| `hdc hilog \| findstr HealthLink` | 看应用日志（排查采集问题很有用） |

### 方式 C：完全命令行构建（无 DevEco 图形界面）

工程里带了一个脚本：

```powershell
cd <项目目录>
pwsh tools/build-phone.ps1
```

⚠️ **但请先看这里**：本机实测时这个脚本**没能跑完**，原因是
hvigor 依赖的两个包（`@ohos/hvigor`、`@ohos/hvigor-ohos-plugin`）
**不在 npmjs 上**（由 DevEco 随包提供），而本机访问不了外网。
我用自建离线 registry 把依赖推进到 298 个包全部解析成功，
最后卡在一个传递依赖 `brace-expansion@^1.1.7`。完整踩坑记录在
[`docs/部署与验证.md` 第三节](部署与验证.md)。

**所以：有外网的机器上用方式 A 或 B 就好，方式 C 只在没网时才值得折腾。**

## 4. 安装后怎么用

1. 手机上找到应用，名字是 **「健康互联」**（图标是蓝底白十字）

2. **先启动电脑端**。双击 `health-link\启动.cmd`，
   它会打印一行要填进手机的地址，例如：
   ```
   ws://192.168.1.100:18787/ingest?token=0123456789abcdef0123456789abcdef
   ```

3. 在手机上：把上面那行**整行**粘贴到「电脑地址」输入框 → 点**保存地址**

4. **连接你的蓝牙设备**（BLE 直连模式，推荐先走这条）
   - 主界面顶部「数据源」卡确认选的是 **BLE 直连**（默认就是）
   - 点 **「连接设备」** → 进蓝牙页 → 点 **「开始扫描」**
   - 找到你的手表/手环/心率带 → 点 **「连接」**
   - **重点看连上后展开的「设备暴露了哪些服务」**：
     - 看到 **`180D`** → 心率能实时读，继续下一步
     - **没有 `180D`** → 这台设备把数据放在厂商私有协议里，BLE 读不到。
       **这不是代码问题**，把这一屏截图保存，见 [`docs/BLE直连模式.md`](BLE直连模式.md)

5. 回到主界面，点 **「开始采集」**。此时应该看到：
   - 状态栏出现 **「HealthLink 正在后台运行」** 的常驻通知
     → **不要删掉它**，删了系统会停止后台采集
   - 连接状态变成 **已连接**（这是连电脑）
   - 数据源状态显示 **已连接 \<你的设备名\>**
   - 「最近采集」开始出现 **心率 xx bpm**

6. 电脑端浏览器打开面板就能看到实时心率曲线

7. **验证后台保活**（这一步最重要）：
   按 Home 键退到后台 → 等 1~2 分钟 → 回到 App
   → 「已发送序号」应该继续增长。如果停住了，见第 7 节。

### 4.1 如果你要走华为 Health Service Kit（能读睡眠/血氧/HRV/压力）

在「数据源」卡切到 **华为 Health Service Kit**，然后：

- 点 **「请求健康数据授权」** → 弹窗里同意
- 成功：显示「通过 N 项，未通过 0 项」
- 未通过：看第 6.2 节的错误码对照

> 这条路需要 AGC 审核通过才能拿到数据。没批下来时**先用 BLE 直连**，
> 两条路的产出是同一种协议格式，电脑端完全不用改。

## 5. 没有华为健康数据权限时怎么验证

**推荐：用 BLE 直连。** 它不需要任何华为审核，装上就能读真实心率
（前提是设备支持标准心率服务 `0x180D`）。操作步骤见上面第 4 步，
细节见 [`docs/BLE直连模式.md`](BLE直连模式.md)。

**或者：从电脑端灌模拟数据**，验证电脑端与协议：

```powershell
cd <项目目录>
node tools\phone-sim.js --url "ws://127.0.0.1:18787/ingest?token=<启动器打印的令牌>" --interval 500 --sleep
```

这样电脑端面板会开始滚动心率/血氧/压力曲线和睡眠分期色带，
证明**电脑端 + 协议**完全正常。

## 6. 装不上 / 采集不到，逐条对照

### 6.0 BLE 直连相关

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 扫描不到设备 | 设备没在广播 | **多数手表/手环只在"配对模式"下广播**，先在系统蓝牙设置里让它进入配对状态 |
| 连不上 / 连上就断 | 设备已被系统或厂商 App 占用 | BLE 设备通常只允许一个中心连接，**先断开系统蓝牙设置和厂商 App 里的连接** |
| 连上但没有 `180D` | 厂商私有协议 | **设备限制，非代码问题**。截图保存证据，改用 Health Kit 或其他设备 |
| 有 `180D` 但没数值 | 未佩戴 / 未开始测量 | 戴上设备；有些心率带需贴合皮肤 |
| 报错 201 | 缺蓝牙权限 | 系统设置 → 应用 → 权限 → 打开蓝牙权限 |
| 报错 2900003 | 蓝牙未打开 | 打开手机蓝牙 |

完整排错表见 [`docs/BLE直连模式.md` 第五节](BLE直连模式.md)。

### 6.1 安装阶段

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `hdc list targets` 显示 `[Empty]` | 数据线只充电 / 没开 USB 调试 / 没点允许 | 换数据线、重开 USB 调试、重新插拔并在手机上点"允许" |
| Run 按钮是灰的，设备框显示 `No Devices` | 同上 | 同上；也可 `File → Invalidate Caches` 后重启 DevEco |
| 报 **签名错误** / `signingConfig not found` | 没做第 2 步 | 回第 2 步，勾选自动生成签名 |
| 报 `Failed to install, code: 9568289` | 设备上已有同包名但签名不同的旧版本 | `hdc uninstall com.healthlink.collector` 后重装 |
| 报 **设备不支持的 API 版本** | 手机系统比 `compatibleSdkVersion` 旧 | 改 `mobile/harmonyos/build-profile.json5` 里的 `compatibleSdkVersion`，或升级手机系统 |
| 编译报 ohpm 依赖拉不下来 | 网络问题 | 在 DevEco 里 `File → Sync and Refresh Project`，确认能访问华为仓库 |
| 安装成功但打开就闪退 | 少见，多为 SDK 版本不匹配 | `hdc hilog \| findstr HealthLink` 看崩溃栈 |

### 6.2 采集阶段（错误码直接对应官方含义）

| 错误码 | 官方含义 | 你要做什么 |
| --- | --- | --- |
| **201** | 鉴权失败 | 检查：① AGC 是否已批准该数据权限 ② 签名指纹与 AGC 登记是否一致 ③ 是否在测试用户名单里（测试权限仅限前 100 位用户） |
| **1002702001** | 用户未登录华为账号 | 手机上登录华为账号 |
| **1002703001** | 用户隐私未同意 | **先在手机上打开一次「华为运动健康」App** 并同意隐私政策 |
| 1002701001 | 网络不可用 | 检查网络；确认 `INTERNET` 权限已授予 |
| 801 | 设备不支持 | 该机型能力不足，换设备 |
| 401 | 参数错误 | 一般是 context 传错（本项目已在 UIAbility 里初始化） |

App 内的「运行日志」卡片会直接显示这些错误码，不用连电脑看日志。

### 6.3 华为健康数据权限怎么申请（这是那 15 个工作日的部分）

1. 到 **华为开发者联盟管理中心** → 应用服务 → **Health Service Kit** → 申请服务
2. 勾选需要的数据权限项（**中文命名**，不是 `ohos.permission.*`）：
   - 「心率数据（读）」→ 动态心率 / 静息心率 / HRV
   - 「血氧数据（读）」
   - 「压力数据（读）」
   - 「睡眠数据（读）」
3. 满足资质要求：
   - 企业/社会团体：实缴注册资本 **≥50 万**（基础）/ **≥500 万**（高阶），主体成立 ≥1 年
   - **个人开发者：高阶数据不开放**，且应用需已上架华为应用市场
4. 等审核（官方说明约 **15 个工作日**）
5. 审核通过后还要**申请验证获取正式权限**（测试阶段仅限前 100 位用户）

> 详细依据（含官方文档链接）见
> [`docs/新旧API对照与纠错.md` 第 4 节](新旧API对照与纠错.md)。

## 7. 退后台就断采？逐一排查

| 检查项 | 怎么查 | 期望 |
| --- | --- | --- |
| 长时任务是否申请成功 | App 状态卡「长时任务」一行 | 显示「运行中（bluetoothInteraction + dataTransfer）」 |
| `module.json5` 声明 | 看 `mobile/harmonyos/entry/src/main/module.json5` | `backgroundModes` 含 `bluetoothInteraction`、`dataTransfer`；权限含 `KEEP_BACKGROUND_RUNNING` |
| 通知栏是否被删 | 下拉通知栏 | 常驻通知在；**删掉它系统会停止长时任务** |
| 系统是否判定业务不实 | 反复被取消就要怀疑 | 见 [`docs/长时任务与保活.md` 2.6](长时任务与保活.md)，可按文档调整模式组合 |

官方约束的完整说明（3 秒挂起、10 分钟窗口、DATA_TRANSFER 的 10 分钟进度续期要求等）
在 [`docs/长时任务与保活.md`](长时任务与保活.md)。

## 8. 卸载

```powershell
$hdc = 'D:\Downloads\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe'
& $hdc uninstall com.healthlink.collector
```

或在手机上长按图标卸载。
注意：卸载会清掉 App 里的偏好存储（电脑地址、设备 ID、seq 游标），
重装后需要重新填地址；电脑端会把重装后的手机当成一台新设备（设备 ID 变了）。
